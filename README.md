# Stave

Learn to read music by playing short song excerpts with a computer keyboard, on-screen piano, or MIDI piano.

The static site is in [`dist/`](dist/). To preview it locally:

```sh
python3 -m http.server 8765 --directory dist
```

Pushes to `main` publish `dist/` to GitHub Pages.

Piano samples: Salamander Grand Piano by Alexander Holm, [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/).
