# Phone screen refresh v1

Created with the built-in image generation tool in edit/compositing mode. The screen reference is an actual 390 × 780 mobile viewport capture of the current app, saved at 2× resolution in [mobile-app-reference.png](mobile-app-reference.png).

Previous artwork assets remain untouched. New PNG masters and lossless WebP delivery files are saved in `dist/assets/phone-screens/`.

## original

Original: `dist/assets/play-on/phone.webp`

New master: `dist/assets/phone-screens/phone-original-app-v1.png`

Delivery: `dist/assets/phone-screens/phone-original-app-v1.webp`

Prompt:

Use case: compositing. Edit only the contents inside the phone display in Image 1. Image 1 is the edit target; Image 2 is an actual screenshot of the current mobile app and must be used as the screen reference. Faithfully perspective-map the actual screenshot into the phone screen, preserving its layout, cream colors, real logo and header 'Real Sight Reader', small tagline, Beginner / Intermediate / Advanced selector, Für Elise song heading, play and settings controls, a single treble staff of music, and the realistic on-screen piano keyboard. The actual screenshot should fill the phone display naturally, clipped beneath any existing notch or camera area. Prioritize reproducing the real app interface and its spacing rather than inventing a generic music screen. Preserve all pixels outside the display as closely as possible: keep phone body, size, location, perspective, lighting, edges, shadows and surrounding graphic decorations unchanged. Do not add any words or devices outside the screen. No captions, no watermark. Preserve the input image framing. This first image is a transparent-background original phone cutout. Preserve its transparent background and the existing tilted 3D phone casing.
